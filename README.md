# Pinterest Quick Save

Pinterest のピンを、あらかじめ決めた保存先(ボード/セクション)へ、S キー1つで保存するユーザースクリプトです。保存済みのピンでもう一度押すと、保存が解除されます。

- 対象サイト: `https://jp.pinterest.com/*`(日本語表示のみ)
- 外部との通信はありません。設定はユーザースクリプト拡張のストレージに保存されます。

## インストール

1. [Tampermonkey](https://www.tampermonkey.net/) などのユーザースクリプト拡張を入れます。
2. [pinterest-quick-save.user.js](https://raw.githubusercontent.com/nut753908/pinterest-quick-save/main/pinterest-quick-save.user.js) を開き、インストールします。

## 使い方

1. 画面右下のパネルで、保存先のボードと(必要なら)セクションを選びます。
2. 保存したいピンにマウスを乗せて **S キー**を押します(パネルの「保存/解除 (S)」ボタンでも同じです)。
3. すでに保存済みのピンで押すと、保存が解除されます。

### 候補について

- ボードやセクションの候補は、Pinterest の保存先の一覧を一度開くと自動で取り込まれます。
- パネルの「候補の管理」で、不要な候補を削除できます。
- 保存に使った保存先は「履歴」に残り、クリックでその保存先に切り替えられます。

### 注意

- マウスがピンの上にないときは、S キーは何もしません(Pinterest 本来のキー操作をそのまま通します)。
- 文字入力中(入力欄を操作しているとき)は反応しません。
- Pinterest の画面構成が変わると動かなくなることがあります。

## 保存キーの変更

スクリプト冒頭の `HOTKEY`(既定は `KeyS`)を、`KeyA` などの別のキーコードに書き換えてください。
